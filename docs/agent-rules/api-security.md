# API, Exception, Security and External API Rules

이 문서는 Controller, DTO, API, 예외, 인증·인가, Redis, CORS와 외부 API 작업에
적용합니다. 작업 전 최상위 `AGENTS.md`도 함께 확인합니다.

## 1. DTO와 검증 

- Request DTO와 Response DTO를 분리합니다.
- 필수 여부, 공백, 길이, 형식, 최솟값, 날짜 범위를 필드별로 정의합니다.
- 문자열 앞뒤 공백과 응답 `null` 필드 정책을 프로젝트 전체에서 통일합니다.
- Domain 객체를 직접 응답하지 않습니다.
- 민감정보와 불필요한 내부 상태를 응답하지 않습니다.

## 2. API

- URL은 `/api`로 시작하고 동사보다 자원 명사를 사용합니다.
- 여러 단어의 경로는 `kebab-case`, JSON 필드는 `camelCase`를 사용합니다.
- API 명세에 없는 응답 필드를 임의로 추가하지 않습니다.
- 목록은 필요에 따라 페이지네이션을 적용합니다.
- 성공·실패 응답은 기존 `ApiResponse<T>` 구조를 유지합니다.
- 삭제처럼 본문이 없는 `204 No Content`에는 응답 본문을 넣지 않습니다.

주요 상태 코드는 다음 기준을 사용합니다.

| 상태 | 용도 |
| --- | --- |
| `200` | 조회·수정 성공 |
| `201` | 생성 성공 |
| `204` | 본문 없는 삭제 성공 |
| `400` | 잘못된 요청 |
| `401` | 인증 실패 |
| `403` | 권한·소유권 부족 |
| `404` | 리소스 없음 |
| `405` | 지원하지 않는 메서드 |
| `409` | 중복·상태 충돌 |
| `413` | 업로드 용량 초과 |
| `500` | 일반화된 서버 오류 |
| `503` | 외부 서비스 장애 등 일시적 이용 불가 |

## 3. 예외 처리

- 공통 `ErrorCode`에는 HTTP 상태, 내부 오류 코드, 사용자 메시지를 둡니다.
- 공통 오류는 `CommonErrorCode`, 도메인 오류는 도메인별 ErrorCode Enum으로 분리합니다.
- 예상 가능한 오류는 `ErrorCode`를 포함한 `BusinessException`으로 처리합니다.
- `GlobalExceptionHandler`가 `BusinessException`과 검증 오류를 공통 응답으로 변환합니다.
- 처리하지 않은 예외는 서버에 기록하되 일반화된 `500`만 응답합니다.
- HTTP 상태와 내부 오류 코드는 반드시 일대일일 필요가 없습니다.

## 4. JWT와 소유권

- Spring Security와 JWT를 사용합니다.
- Access Token은 일반 DB에 저장하지 않습니다.
- Refresh Token은 Redis에 저장하고 토큰 만료시간과 같은 TTL을 설정합니다.
- 로그아웃 시 Refresh Token을 삭제하거나 무효화합니다.
- 요청의 `userId`를 신뢰하지 않고 인증된 JWT에서 현재 사용자를 식별합니다.
- 사용자 소유 리소스는 조회·변경 전 반드시 소유권을 확인합니다.
- 계좌번호는 API 응답에서 마스킹합니다.

## 5. Redis

Redis는 Refresh Token 저장·만료·재발급 검증 용도로 사용합니다.
회원, 계좌·자산, 거래, 목표·로드맵, 금융상품, 자동저금 이력,
AI 코치 대화처럼 영구 보관할 데이터는 MySQL에 저장합니다.

Redis 용도를 추가하려면 캐시 대상, TTL, 원본 저장소와 불일치 처리 방식을 먼저 정의합니다.

## 6. CORS와 설정 보안

- 허용 Origin은 Vue 개발·배포 환경별 설정으로 관리합니다.
- 실제 사용하는 Origin, HTTP 메서드, `Authorization`, `Content-Type` 등 필요한 항목만 허용합니다.
- 인증정보가 포함된 요청에는 와일드카드 Origin을 사용하지 않습니다.
- Spring Security와 중복·충돌하지 않도록 CORS 정책을 한 곳에서 관리합니다.
- 비밀번호, JWT Secret, 외부 API Key를 코드에 하드코딩하지 않습니다.

## 7. 외부 API

- 외부 응답 DTO와 내부 Domain을 분리하고 매핑 과정에서 내부 필드명으로 변환합니다.
- `null`, 누락 필드, 빈 목록, 오류 코드를 처리합니다.
- 외부 호출 실패 시 기존 데이터를 삭제하지 않습니다.
- 외부 API 호출과 데이터 저장을 Controller에서 직접 처리하지 않습니다.
- 금융감독원 상품은 금융기관 코드와 상품 코드를 기준으로 UPSERT합니다.
- OpenAI 기능은 `gpt-5-nano`, `gpt-4o-mini`만 사용하고 모델 선택은 설정으로 관리합니다.
